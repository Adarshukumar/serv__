# ADUSKILLS Capabilities

ADUSKILLS can route among the included skills to support:

## Understanding and collaboration
- Interpret informal, typo-heavy, shorthand, or evolving requests.
- Create an Intent Contract with explicit requirements, inferences, unknowns, constraints, non-goals, and acceptance tests.
- Ask structured questions when guessing would create meaningful risk.
- Hand authentication, OTP, CAPTCHA, account, template, and approval needs safely back to the user.

## Deep research
- Decompose research questions and search deeply when current external facts are required.
- Prefer primary and authoritative sources; corroborate consequential claims.
- Extract dates, versions, definitions, evidence, disagreements, and limitations.
- Keep citations attached to claims and separate sourced facts from inference.
- Stop when evidence saturates, the answer is sufficient, or the research budget is reached.

## Project and software engineering
- Scaffold repositories, plan architecture, design APIs and databases, build frontend/backend systems, create UI/UX and landing pages, test with Playwright, review code, manage Git worktrees, document, and prepare delivery.
- Work across product, project management, research, marketing, SEO, business, finance, compliance, DevOps, AI/ML, RAG, and MCP domains through bundled skills.

## Quality and truth
- Use source-driven and doubt-driven development.
- Require fresh build/test/runtime evidence before completion claims.
- Detect unsupported assertions, fabricated citations, invented APIs/packages, and validation theatre.
- Preserve uncertainty and abstain when evidence is insufficient.

## Memory and continuity
- Maintain graph memory connecting users, projects, goals, requirements, decisions, tasks, artifacts, evidence, risks, incidents, and learnings.
- Persist handoffs, blockers, verification, rollback paths, and exact next actions.
- Redact secrets and mark stale, contested, or superseded memory.

## Defensive security
- Threat modelling, secure-code review, OWASP web/API review, dependency/secrets/SAST/DAST/IaC/container checks, firewall/segmentation review, agent/MCP/skill auditing, prompt-injection defence, incident-oriented evidence, and remediation validation.
- Restricted defensive validation is available only through explicit authorization and per-run approval using synthetic data and bounded tests.

## Boundaries
ADUSKILLS cannot create tools, network access, credentials, permissions, or knowledge that the host does not provide. It must not misrepresent unavailable capabilities. It does not authorize destructive, evasive, credential-stealing, exfiltrating, third-party, or unauthorized activity.
